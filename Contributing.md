# Contributing

Contributions are welcome!

## How to contribute

- Search the existing list to avoid duplicates.
- Only suggest awesome items: the best in their category, not everything that exists.
- Only suggest items that are maintained, with documentation, and not archived or deprecated.
- Add the item once, under the correct browser and subcategory. Do not duplicate the same extension under Chromium, Google Chrome, and Microsoft Edge, because Chrome Web Store extensions work on all Chromium-based browsers.
- Add the item in alphabetical order, in the correct browser and subcategory.
- Use this format: `- [Name](link) - Description.`
- The description must start with an uppercase character and end with a period.
- Do not add items without a description, unless the title alone is fully descriptive.
- Do not add empty sections. Only add a new browser section when you have at least one awesome entry for it.

## Browsers wanted

- Firefox and Safari are not yet covered, because they use different extension stores. Contributions for Firefox and Safari are especially welcome.
- Brave, Opera, Vivaldi, and Arc do not need separate sections, because they are Chromium-based and can use the extensions listed under Google Chrome.

## Pull requests

- Keep each pull request focused on one item or one small change.
- Explain why the item deserves to be on the list.
